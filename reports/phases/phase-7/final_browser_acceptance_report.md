## 1. Real Defects Uncovered & Surgically Fixed During Live Browser Testing

Operating the UI through physical DOM clicks in Google Chrome exposed real state-synchronization and UI-lifecycle defects that pure HTTP/API tests could not detect. Each was surgically resolved:

1. **PostCSS `.shadow-panel` Compilation Failure ([`src/index.css`](file:///C:/Users/admin/.gemini/antigravity/scratch/financial-immune-system/src/index.css#L72-L76))**
   - **Defect:** `@apply shadow-panel` failed at runtime in PostCSS when arbitrary utility classes were resolved inside `@layer components`.
   - **Fix:** Replaced `@apply` with explicit CSS `box-shadow: 0 10px 30px -10px rgba(0, 0, 0, 0.7), inset 0 1px 0 0 rgba(255, 255, 255, 0.05)` while preserving the token in [`tailwind.config.js`](file:///C:/Users/admin/.gemini/antigravity/scratch/financial-immune-system/tailwind.config.js#L29-L36).
2. **Role Selector Modal DOM Click Propagation ([`src/components/auth/RoleSelector.tsx`](file:///C:/Users/admin/.gemini/antigravity/scratch/financial-immune-system/src/components/auth/RoleSelector.tsx#L91-L162))**
   - **Defect:** Role cards relied solely on parent card click propagation and rendered raw string icon names.
   - **Fix:** Bound explicit `onClick` handlers to the `"Assume Identity →"` button and role cards, and mapped role icons to Lucide components (`Shield`, `Terminal`, `AlertTriangle`, `FileCheck`, `Eye`).
3. **Verification View Premature Recovery Masking ([`src/views/VerificationView.tsx`](file:///C:/Users/admin/.gemini/antigravity/scratch/financial-immune-system/src/views/VerificationView.tsx#L48-L51))**
   - **Defect:** `VerificationView` computed `isRecovered` using `margin >= 80 || ...`, which allowed raw simulation margin changes to mask an active `VERIFIED_FAILED` enclave verdict when `Simulate Residual Contagion` was checked.
   - **Fix:** Prioritized authoritative enclave verification state (`foundryState.latest_verification.verification_result === 'VERIFIED_EFFECTIVE' || observed_outcome === 'CONTROL_RESTORED'`) over raw margin when a verification record exists.
4. **Enclave Verifier Seed Timestamp Staleness ([`server/src/foundry/independentVerifier.ts`](file:///C:/Users/admin/.gemini/antigravity/scratch/financial-immune-system/server/src/foundry/independentVerifier.ts#L54-L62)) & Foundry Workspace Sync ([`server/src/foundry/foundryManager.ts`](file:///C:/Users/admin/.gemini/antigravity/scratch/financial-immune-system/server/src/foundry/foundryManager.ts#L402-L404))**
   - **Defect:** Comparing static seed evidence timestamps against wall-clock `Date.now()` caused Evaluation Gate 1 (`EVIDENCE_STALE`) to preempt Evaluation Gate 3 (`RESIDUAL_HAZARD`), routing escalation to `EVD-REFRESH` instead of `MODEL-QUARANTINE-BACKSTOP`. Furthermore, `engine.step()` ran before `this.latestVerification` was assigned, leaving `engine.controlState.foundry` one step behind on SSE ticks.
   - **Fix:** Evaluated evidence freshness against enclave telemetry status (`12s` live heartbeat unless `forceStaleEvidence` is active) and synchronized `engine.controlState.foundry = this.getWorkspaceState(engine)` immediately after verification completes.
5. **Global Header Equilibrium Status Alignment ([`src/components/shell/AppHeader.tsx`](file:///C:/Users/admin/.gemini/antigravity/scratch/financial-immune-system/src/components/shell/AppHeader.tsx#L40-L43), [`NavigationSidebar.tsx`](file:///C:/Users/admin/.gemini/antigravity/scratch/financial-immune-system/src/components/shell/NavigationSidebar.tsx#L118-L120), [`OperationalContextBar.tsx`](file:///C:/Users/admin/.gemini/antigravity/scratch/financial-immune-system/src/components/shell/OperationalContextBar.tsx#L39-L41))**
   - **Defect:** Global chrome checked `scenarioState === 'ATTACK_ACTIVE'` without checking whether `controlState.overall_status` had returned to `'STABLE'`.
   - **Fix:** Updated `isAttack` to `scenarioState === 'ATTACK_ACTIVE' && controlState.overall_status !== 'STABLE'`, restoring `"EQUILIBRIUM: ALL CHANNELS NOMINAL"` immediately upon verified backstop recovery.
6. **React Duplicate Key Warning in Event Detection ([`src/views/EventDetectionView.tsx`](file:///C:/Users/admin/.gemini/antigravity/scratch/financial-immune-system/src/views/EventDetectionView.tsx#L204-L209))**
   - **Defect:** Re-injecting scenarios produced duplicate key warnings on `RN-2026-0041`.
   - **Fix:** Scoped row keys to `${evt.id}-${idx}`, achieving `0` console warnings/errors across the entire 12-step run.
