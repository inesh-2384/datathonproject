## 1. Primary Research Limitations

A serious research project must state clearly where its knowledge ends. The Financial Immune System prototype has the following documented limitations:

### 1. Simulation Dependence & Synthetic Topology
- **Current Reality:** All 20 financial institutions, 102 dependencies, and market oracle feeds are synthetic data models generated by the deterministic PRNG engine (`seed: 42091`).
- **Limitation:** While structurally calibrated to real Tier-1 G-SIB interbank networks and clearing house relationships, the network does not reflect real-time live banking transaction volumes or confidential balance sheets.
- **Future Work:** Calibrate topology parameters against anonymized regulatory data sets (e.g., Federal Reserve FR Y-14 or DTCC trade repository aggregates).

### 2. Absence of Physical IBM Z Hardware Execution
- **Current Reality:** The system runs locally in Node.js v24 / TypeScript on a Windows workstation.
- **Limitation:** IBM LinuxONE Secure Execution enclaves, Crypto Express 8S HSMs, and on-chip Telum co-processors are simulated via software abstractions and cryptographic libraries.
- **Future Work:** Package the control enclave as an s390x container image and benchmark real CPACF hardware throughput on an IBM LinuxONE Community Cloud instance.

### 3. Heuristic Parameter Calibration
- **Current Reality:** Parameter weights ($w_{\text{prop}} = 4.0$, $w_{\text{HHI}} = 6.0$, $w_{\text{EDD}} = 34.0$) were calibrated through experimental sensitivity sweeps and multi-scenario tuning.
- **Limitation:** These weights are not econometric estimates derived from historical financial crises (e.g., 2008 Lehman collapse, 2023 Silicon Valley Bank run).
- **Future Work:** Apply maximum likelihood estimation (MLE) or Bayesian parameter updating on historical bank default and liquidity stress records.

### 4. Discrete Intervention Space
- **Current Reality:** The Control Foundry evaluates four discrete intervention archetypes: `DEPENDENCY_ISOLATION`, `MODEL_DIVERSIFICATION`, `DATA_QUARANTINE`, and `EXPOSURE_REDUCTION`.
- **Limitation:** Real-world central bank and regulatory interventions involve complex continuous legal instruments (e.g., dynamic discount window access, bilateral asset swap facilities, emergency regulatory forbearance).
- **Future Work:** Extend candidate generation to continuous optimization spaces using multi-agent reinforcement learning.

### 5. Simplified Market Microstructure
- **Current Reality:** Asset liquidation and fire-sale dynamics are modeled through discrete exposure weights and status transitions.
- **Limitation:** Complex market microstructure phenomena—such as order book depth slippage, limit order replenishment, and cross-venue latency arbitrage—are simplified into topological cascade hops.
